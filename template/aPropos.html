Ressources API-Steam

Cette application web a été développée dans le cadre d'un projet académique visant à explorer les ressources offertes par l'API RAWG. L'objectif principal de cette application est de permettre aux utilisateurs de rechercher, consulter et gérer une collection de jeux vidéo disponibles sur la plateforme RAWG.

Les fonctionnalités clés de l'application incluent :

  • Recherche avancée de jeux vidéo en utilisant divers critères tels que le titre, le genre, la date de sortie, etc.
  • Affichage détaillé des informations sur chaque jeu, y compris les descriptions, les images, les évaluations et les prix.
  • Gestion d'une collection personnelle de jeux favoris pour un accès rapide et facile.

Nous espérons que cette application sera utile aux passionnés de jeux vidéo et qu'elle facilitera la découverte de nouveaux titres sur la plateforme RAWG.
