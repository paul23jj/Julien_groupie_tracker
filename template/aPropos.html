Ressources API-RAWG

Cette application web a été développée dans le cadre d'un projet académique visant à explorer les ressources offertes par l'API RAWG. L'objectif principal de cette application est de permettre aux utilisateurs de rechercher, consulter et gérer une collection de jeux vidéo disponibles sur la plateforme RAWG.

Technologies Utilisées et Architecture Technique :

Frontend : HTML et CSS pour une interface moderne et responsive.
Backend : Go pour la gestion des requêtes, le traitement des données et l'interaction avec l'API RAWG.
Collaboration : Git et GitHub pour le contrôle de version et la collaboration entre les membres de l'équipe.

Les fonctionnalités clés de l'application incluent :

  • Recherche avancée de jeux vidéo en utilisant divers critères tels que le titre, le genre, la date de sortie, etc.
  • Affichage détaillé des informations sur chaque jeu, y compris les descriptions, les images, les évaluations et les prix.
  • Gestion d'une collection personnelle de jeux favoris pour un accès rapide et facile.

Défis rencontrés :

  • Intégration de l'API RAWG et gestion des limites de requêtes.
  • implementation du systeme de filtre.
  • Implementation du systeme de favoris.

Competances acquises : Maîtrise de HTM et CSS, intégration d'API externes, gestion des requêtes asynchrones avec Fetch, et développement de bonnes pratiques web. Point fort du projet : Code propre et bien structuré, interface responsive et performante, intégration réussie de l'API RAWG, respect des délais. Ameliorations futures : Ajouter des fonctionnalités sociales et systeme de connection utilisateurs.

Nous espérons que cette application sera utile aux passionnés de jeux vidéo et qu'elle facilitera la découverte de nouveaux titres sur la plateforme RAWG.
